# Rangkuman Kajian

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Astro, Tailwind CSS, shadcn/ui and React islands. Python CLI generates notes locally. npm manages the frontend.

## Users
The project owner generates, reviews, and studies Indonesian kajian privately on a Mac. The website also supports mobile viewport sizes.

## Product Purpose
Read, revisit, and apply kajian material while being able to inspect the passages and external references behind each point.

## Operating Context
Markdown remains editable in an external editor. The local website and CLI use the same Python generation and review pipeline. The website provides transcript imports, one job at a time, saved progress, retries, a library, and evidence review. Browser storage holds personal study state. Job history and owner decisions live on disk. No accounts, network hosting, batch queues, browser editor, or AI chat.

## Product Principles
- Preserve the speaker's meaning and Q&A coverage.
- Distinguish retrieved references and AI applications from the speaker's words.
- Show uncertain and stale findings honestly.
- Reading takes priority over controls and verification detail.

## Confirmed Visual Direction
Book with margin notes: warm paper, serif article text, quiet green accents, continuous articles and on-demand evidence. Build directly in code.

## Accessibility
Keyboard navigation, labelled review states, readable contrast, text resizing, Arabic direction, responsive layout, and usable content without browser storage.
